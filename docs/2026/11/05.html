오늘의 기술

AI 에이전트 연결 규약: MCP와 A2A

트렌드 픽 AI/ML ⏱ 6분

AI 에이전트 연결 규약은 모델이 외부 도구(MCP)나 다른 에이전트(A2A)와 정해진 형식으로 정보를 주고받게 하는 표준 약속이다.

왜 필요한가

에이전트가 실제 일을 하려면 주문 조회, 파일 읽기, 결제 같은 외부 기능을 불러야 한다. 규약이 없으면 도구마다, 모델마다 연결 코드를 따로 짜야 해서 M개의 앱과 N개의 도구를 잇는 데 M×N개의 어댑터가 필요하다. 표준이 생기면 한쪽만 규약을 지키면 어디서든 붙는다. 실제로 오늘 뉴스에서도 국내 플랫폼의 통합 에이전트, 여러 에이전트를 병렬로 돌리는 코딩 도구가 나왔고, 에이전트끼리의 호출 규약인 A2A는 스펙대로 동작하는지 검증한 글까지 나왔다.

MCP(Model Context Protocol)는 에이전트와 도구·데이터 사이의 연결을, A2A(Agent2Agent)는 에이전트와 에이전트 사이의 협업을 다룬다. 둘은 경쟁이라기보다 층이 다르다고 보는 것이 일반적이다.

동작 원리

  1. 도구 연결(MCP): 에이전트(호스트)가 MCP 서버에 접속해 "어떤 도구가 있는지"를 묻고, 각 도구의 이름·설명·입력 스키마를 받는다.
  2. 모델의 선택: LLM이 사용자의 요청과 도구 목록을 보고 어떤 도구를 어떤 인자로 부를지 결정한다.
  3. 호출과 결과 반환: 호스트가 JSON-RPC 요청으로 도구를 실행하고, 결과를 모델 문맥에 넣어 다음 판단을 이어 간다.
  4. 에이전트 발견(A2A): 다른 에이전트와 협업할 때는 상대의 에이전트 카드(이름, 기능, 인증 방식을 적은 JSON)를 먼저 읽는다.
  5. 작업 위임(A2A): 클라이언트 에이전트가 작업(task)을 만들어 보내면, 서버 에이전트는 진행 상태를 알리고 필요하면 취소 요청을 받는다. 결과는 산출물(artifact)로 돌려준다.
  6. 보안 확인: 카드에 인증을 선언했더라도 서버가 실제로 검사하는지는 따로 확인해야 한다.

예시

에이전트 카드는 상대 에이전트가 자신을 소개하는 JSON 문서다. 아래는 개념을 보여 주기 위한 단순화한 예시이며, 실제 스펙의 필드 이름은 버전에 따라 다를 수 있다.

{
  "name": "refund-agent",
  "description": "환불 요청을 검토하고 처리 상태를 알려 준다",
  "url": "https://agents.example.com/refund",
  "capabilities": { "streaming": true },
  "authentication": { "schemes": ["bearer"] },
  "skills": [
    { "id": "check-refund", "description": "주문 번호로 환불 가능 여부를 확인한다" }
  ]
}

MCP 쪽은 도구를 파이썬 함수로 선언하는 것이 간단하다. 아래는 공식 파이썬 SDK의 FastMCP 스타일을 따른 예시다.

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("order-tools")

@mcp.tool()
def get_order_status(order_id: str) -> str:
    """주문 번호로 배송 상태를 조회한다."""
    return f"{order_id}: 배송 중"

if __name__ == "__main__":
    mcp.run()

함수 이름, 타입 힌트, 독스트링이 그대로 도구 설명과 입력 스키마가 되어 모델에게 전달된다. 단, 카드에 적힌 인증이 서버에서 강제되는지는 코드가 아니라 설정과 테스트로 확인해야 한다.

언제 쓰고 언제 안 쓰나

쓰면 좋은 경우 - 같은 도구를 여러 에이전트나 앱에서 재사용하고 싶을 때(MCP) - 서로 다른 팀·회사가 만든 에이전트가 오래 걸리는 작업을 위임하고 진행 상황을 확인해야 할 때(A2A)

피해야 할 경우 - 호출할 함수가 두세 개뿐인 단순한 앱: 직접 함수 호출이나 일반 HTTP API가 더 가볍다. A2A를 검증한 글에서도 규약을 쓰면 응답 크기와 지연 시간이 늘었다. - 인증을 규약이 알아서 해 준다고 믿는 경우: 선언된 인증이 실제로 강제되는지는 서버 설정과 테스트로 확인해야 한다. - 출처가 불분명한 MCP 서버를 그대로 연결하는 경우: 도구 설명과 결과가 모델 입력이 되므로 악성 지시가 섞일 수 있다.

또한 사용자 수요가 아직 작을 수 있다는 점도 기억하자. 우버는 에이전트로 예약된 승차가 한 주에 4건뿐이라고 밝혔다.
