오늘의 기술

OWASP Top 10

커리큘럼 #23 보안 ⏱ 5분

OWASP Top 10은 웹 애플리케이션에서 가장 흔하고 위험한 보안 취약점 범주 10가지를 정리해 주기적으로 발표하는 인식 제고 문서다.

왜 필요한가

소프트웨어는 기능을 먼저 만들고 보안은 나중에 생각하기 쉽다. 그러다 보면 같은 실수가 프로젝트마다 반복된다. 입력값을 그대로 쿼리에 붙이거나, 권한 확인을 빠뜨리거나, 오래된 라이브러리를 방치하는 식이다.

OWASP(Open Worldwide Application Security Project)는 비영리 보안 커뮤니티다. 실제 사고와 취약점 데이터를 바탕으로 "가장 자주 터지는 문제"를 순위로 묶어 공개한다. 덕분에 개발자, 리뷰어, 보안 담당자가 같은 용어로 위험을 이야기할 수 있다. 신입 개발자에게는 무엇부터 조심해야 하는지 알려 주는 체크리스트 역할을 한다.

참고로 이 문서는 법적 표준이 아니라 우선순위 가이드다. 새 판이 나올 때마다 순위와 항목 이름이 바뀌므로 최신 판을 확인하는 습관이 필요하다.

동작 원리

Top 10의 항목은 판마다 조금씩 다르지만, 꾸준히 상위권에 오르는 범주는 비슷하다.

  1. 접근 제어 실패(Broken Access Control): 로그인은 했지만 남의 데이터를 볼 수 있는 경우다. URL의 /orders/123을 /orders/124로 바꾸면 남의 주문이 열리는 식이다.
  2. 암호화 실패: 비밀번호를 평문이나 약한 해시로 저장하거나, 민감한 정보를 암호화 없이 전송한다.
  3. 인젝션(Injection): 사용자 입력이 쿼리나 명령어의 일부로 해석된다. SQL 인젝션이 대표적이다.
  4. 안전하지 않은 설계와 잘못된 설정: 기본 비밀번호, 불필요하게 열린 포트, 자세한 에러 메시지 노출 등이다.
  5. 취약하거나 오래된 구성 요소: 알려진 취약점이 있는 라이브러리를 계속 쓰는 경우다.
  6. 인증 실패: 약한 비밀번호 허용, 로그인 시도 횟수 제한 없음, 세션 관리 미흡 등이다.
  7. 무결성 실패와 로깅·모니터링 부족: 신뢰할 수 없는 업데이트나 데이터를 검증 없이 쓰고, 공격이 있어도 기록과 경보가 없다.

공통 원리는 두 가지다. 신뢰할 수 없는 입력은 항상 검증하고 데이터와 명령을 분리한다. 그리고 서버에서 매번 권한을 확인한다.

예시

SQL 인젝션은 가장 고전적인 예다. 아래 Python 코드는 입력값을 문자열로 이어 붙여서 위험하다.

import sqlite3

conn = sqlite3.connect(":memory:")
conn.execute("CREATE TABLE users (name TEXT, secret TEXT)")
conn.execute("INSERT INTO users VALUES ('alice', 's3cret')")

name = "x' OR '1'='1"

# 취약: 입력이 SQL 문장의 일부가 된다
bad = conn.execute(f"SELECT * FROM users WHERE name = '{name}'").fetchall()
print("취약:", bad)   # 모든 행이 나온다

# 안전: 파라미터 바인딩으로 입력을 값으로만 취급한다
good = conn.execute("SELECT * FROM users WHERE name = ?", (name,)).fetchall()
print("안전:", good)  # []

첫 쿼리는 조건이 항상 참이 되어 전체 테이블이 노출된다. 두 번째처럼 ? 자리표시자를 쓰면 입력 전체가 이름 값으로만 비교되어 공격이 통하지 않는다.

언제 쓰고 언제 안 쓰나

쓰면 좋은 경우 - 새 프로젝트의 코드 리뷰 체크리스트나 보안 교육 자료를 만들 때 - 팀이 보안 작업의 우선순위를 정해야 할 때 - 취약점 진단 결과를 범주별로 분류해 설명할 때

주의할 점 - 목록의 10개만 막았다고 안전해지지는 않는다. 이 문서는 최소한의 출발점이다. - 순위는 통계 기반이라 우리 서비스의 실제 위험과 다를 수 있다. 서비스 특성에 맞는 위협 모델링을 함께 해야 한다. - 항목 이름을 외우기보다, 각 항목이 어떤 실수에서 생기는지 이해하는 편이 오래 남는다.
