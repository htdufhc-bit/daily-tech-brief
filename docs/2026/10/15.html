오늘의 기술

트랜스포머 구조

커리큘럼 #6 AI/ML ⏱ 6분

트랜스포머는 입력 문장의 모든 단어가 서로를 직접 참조하게 하는 어텐션(attention) 연산만으로 순서 데이터를 처리하는 신경망 구조다.

왜 필요한가

트랜스포머 이전의 표준은 RNN과 LSTM이었다. 이 모델들은 단어를 앞에서부터 하나씩 순서대로 처리하기 때문에 두 가지가 불편했다.

  • 병렬화가 어렵다: 다음 단어의 계산이 이전 단어의 결과에 의존해서, GPU를 충분히 활용하지 못한다.
  • 먼 거리의 관계를 잊는다: 문장이 길어지면 앞쪽 정보가 여러 단계를 거치며 희미해진다.

2017년 논문 "Attention Is All You Need"는 순환 구조를 아예 없애고 어텐션만 쓰는 구조를 제안했다. 모든 위치를 한꺼번에 계산할 수 있어 학습이 빨라졌고, 어떤 두 단어든 한 번의 연산으로 연결된다. 오늘날 대형 언어 모델 대부분이 이 구조 위에서 만들어진다.

동작 원리

트랜스포머의 핵심은 셀프 어텐션이다. 한 문장이 들어왔을 때의 흐름은 다음과 같다.

  1. 토큰화와 임베딩: 문장을 토큰으로 나누고 각 토큰을 숫자 벡터로 바꾼다.
  2. 위치 인코딩: 어텐션은 순서를 모르기 때문에, 각 토큰의 위치 정보를 벡터에 더해 준다.
  3. Q, K, V 만들기: 각 토큰 벡터에 서로 다른 가중치 행렬을 곱해 질의(Query), 키(Key), 값(Value) 세 벡터를 만든다.
  4. 유사도 계산: 한 토큰의 Q와 모든 토큰의 K를 내적해 "얼마나 관련 있는가" 점수를 구하고, 차원 크기의 제곱근으로 나눈 뒤 소프트맥스로 합이 1인 가중치로 바꾼다.
  5. 가중합: 그 가중치로 V들을 섞어 해당 토큰의 새 표현을 만든다. 관련 깊은 단어의 정보가 더 많이 반영된다.
  6. 멀티 헤드: 3~5를 여러 묶음(헤드)으로 나눠 동시에 하고 이어 붙인다. 헤드마다 문법, 대상 지칭 같은 서로 다른 관계를 잡는다.
  7. 피드포워드와 정규화: 각 토큰에 작은 신경망을 적용하고, 잔차 연결(residual)과 층 정규화로 안정적으로 학습한다. 이런 블록을 여러 층 쌓는다.

원 논문은 입력을 읽는 인코더와 출력을 만드는 디코더를 모두 두었다. GPT 계열처럼 디코더만 쓰는 모델은 "자기 앞의 토큰만 볼 수 있게" 마스크를 씌워 다음 단어를 예측한다.

예시

아래는 NumPy로 쓴 단일 헤드 셀프 어텐션의 핵심이다. 입력 x의 각 행이 토큰 하나다.

import numpy as np

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

def self_attention(x, Wq, Wk, Wv):
    Q, K, V = x @ Wq, x @ Wk, x @ Wv
    scores = Q @ K.T / np.sqrt(K.shape[-1])
    weights = softmax(scores)      # 각 행의 합이 1
    return weights @ V, weights

rng = np.random.default_rng(0)
x = rng.normal(size=(4, 8))        # 토큰 4개, 차원 8
Wq, Wk, Wv = (rng.normal(size=(8, 8)) for _ in range(3))
out, w = self_attention(x, Wq, Wk, Wv)
print(out.shape)                   # (4, 8)
print(w.sum(axis=-1))              # [1. 1. 1. 1.]

출력은 입력과 같은 모양이지만, 각 토큰이 다른 토큰들의 정보를 가중치대로 섞어 받은 값이다. weights를 찍어 보면 어떤 토큰이 어떤 토큰을 얼마나 보는지 직접 확인할 수 있다.

언제 쓰고 언제 안 쓰나

쓰면 좋은 경우

  • 텍스트, 코드, 음성처럼 긴 순서 데이터에서 먼 위치 사이의 관계가 중요할 때
  • 대량의 데이터와 GPU로 병렬 학습할 수 있을 때
  • 이미 공개된 사전 학습 모델을 가져와 미세 조정할 수 있을 때

피해야 할 경우

  • 어텐션은 길이 n에 대해 계산량과 메모리가 n의 제곱으로 늘어서, 아주 긴 입력에는 비용이 크다. 긴 문맥용 변형 기법을 따로 살펴봐야 한다.
  • 데이터가 적은 작은 문제에는 단순한 모델이 더 낫고 과적합 위험도 낮다.
  • 규칙이 명확한 표 형태 데이터에는 트리 계열 모델이 보통 더 간단하고 강하다.
