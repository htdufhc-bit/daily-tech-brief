오늘의 기술

Git 내부 구조

커리큘럼 #8 언어/도구 ⏱ 5분

Git은 파일 내용을 해시로 식별하는 **콘텐츠 주소 지정 저장소** 위에 blob, tree, commit 객체와 참조(ref)를 쌓아 버전 관리를 구현한다.

왜 필요한가

버전 관리 도구가 풀어야 할 문제는 "프로젝트의 과거 상태를 싸고 안전하게 전부 보관하고, 여러 사람이 갈라졌다 합치게 하는 것"이다. 변경분(diff)만 순서대로 쌓는 방식은 오래된 버전을 복원하려면 모든 변경을 되감아야 하고, 브랜치를 만들 때마다 비용이 든다.

Git은 매 커밋마다 프로젝트 전체의 스냅샷을 가리키되, 내용이 같은 파일은 해시가 같아 하나만 저장하는 방식을 택했다. 덕분에 브랜치 생성이 포인터 하나를 만드는 일로 끝나고, 해시가 곧 무결성 검사 역할도 하므로 저장소가 손상되거나 몰래 바뀌면 바로 드러난다. 내부 구조를 모르면 reset, rebase, reflog 같은 명령이 "왜 그렇게 동작하는지" 설명되지 않아 외워서 쓰게 된다.

동작 원리

  1. 객체 저장: git add를 하면 파일 내용을 압축해 .git/objects에 저장한다. 파일 이름은 내용의 SHA-1(또는 SHA-256) 해시이므로, 같은 내용은 한 번만 저장된다. 이를 blob이라 부른다.
  2. tree 객체: 디렉터리 한 단계의 스냅샷이다. "이름 → blob 또는 하위 tree의 해시" 목록을 담고 있어, 프로젝트 전체가 해시 트리로 표현된다.
  3. commit 객체: 최상위 tree의 해시, 부모 커밋의 해시, 작성자와 메시지를 담는다. 부모를 따라가면 히스토리가 연결 리스트처럼 이어진다.
  4. 참조(ref): .git/refs/heads/main 같은 작은 텍스트 파일에 커밋 해시 하나만 적혀 있다. 브랜치는 "커밋을 가리키는 이름표"일 뿐이라 만들고 옮기는 비용이 거의 없다.
  5. HEAD: 현재 어느 브랜치(또는 커밋)에 있는지를 가리키는 파일이다. 커밋하면 현재 브랜치의 ref가 새 커밋 해시로 갱신된다.
  6. 팩 파일: 객체가 많아지면 git gc가 비슷한 객체를 델타로 묶어 .git/objects/pack에 압축한다.

예시

직접 객체를 만들어 보며 구조를 확인해 보자. 아래 명령은 빈 디렉터리에서 그대로 실행할 수 있다.

git init demo && cd demo
echo "hello" | git hash-object -w --stdin   # blob 저장, 해시 출력
git cat-file -p ce013625030ba8dba906f756967f9e9ca394464a   # 내용 확인
echo "hi" > a.txt && git add a.txt && git commit -m "first"
git cat-file -p HEAD            # commit: tree, author, message
git cat-file -p HEAD^{tree}     # tree: a.txt -> blob 해시
cat .git/refs/heads/*           # 브랜치 = 커밋 해시 한 줄

hash-object -w는 내용을 객체로 저장하고, cat-file -p는 객체를 사람이 읽을 형태로 보여 준다. 출력된 tree와 blob 해시를 따라가면 커밋이 어떻게 파일로 이어지는지 눈으로 확인할 수 있다.

언제 쓰고 언제 안 쓰나

알아 두면 좋은 경우 - reset --hard나 잘못된 rebase 이후 커밋을 되살려야 할 때: 커밋 객체는 바로 지워지지 않으므로 git reflog로 해시를 찾아 복구할 수 있다. - 저장소가 커졌을 때 원인을 찾을 때: 큰 파일이 blob으로 히스토리에 남아 있으면 지워도 용량이 줄지 않는다. - 커밋 해시가 왜 바뀌는지 이해할 때: 부모나 내용이 바뀌면 해시도 바뀌므로 rebase는 커밋을 "수정"이 아니라 "새로 만드는" 작업이다.

주의할 점 - 객체를 직접 만지는 저수준 명령(plumbing)은 학습과 디버깅용이다. 일상 작업은 add, commit 같은 고수준 명령을 쓰자. - .git 안의 파일을 손으로 고치면 저장소가 깨질 수 있으니 실습은 복사본이나 빈 저장소에서 하자.
